# 🎮 咒术回战：同人策略 RPG (Jujutsu Kaisen Fan RPG)

[![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/XHNotFound/Jujutsu-Kaisen-FanRPG/blob/main/LICENSE)
[![GitHub stars](https://img.shields.io/github/stars/XHNotFound/Jujutsu-Kaisen-FanRPG)](https://github.com/XHNotFound/Jujutsu-Kaisen-FanRPG/stargazers)

基于《咒术回战》世界观开发的 2D 网页端同人 RPG/策略对战游戏。

##  特色功能
- **战斗系统**：ATB 行动条机制，距离拉扯，黑闪，束缚机制
- **领域博弈**：领域展开、对拼、简易领域/落花之情等高级技巧
- **养成**：行动力管理、咒力残秽系统、NPC 请教与职级考核
- **多单位战场**：召唤物系统、仇恨机制与多单位协同作战

## 如何游玩
本游戏为纯前端项目，无需安装任何依赖。
1. **在线游玩**：访问 [GitHub Pages 链接](https://xhnotfound.github.io/Jujutsu-Kaisen-FanRPG/)
